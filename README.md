# CS12HK

Luxury minimal homepage redesign prototype for CS12 Skincare Hong Kong.

## Files

- `index.html` — refined homepage concept
- `styles.css` — visual system and responsive layout
- `script.js` — mobile menu + Chinese / English switcher

## Direction used

- Dior-inspired editorial beauty direction without copying brand assets
- porcelain ivory, champagne, warm espresso and restrained rosewood palette replacing the previous dark/glass treatment
- color system: `#FAF8F4` porcelain base, `#EADFD3` champagne panels, `#211C19` warm espresso type, and `#825F59` rosewood accents
- centered wordmark, restrained type scale, fine rules and square editorial layouts
- Traditional Chinese first with English switch preserved
- subtle scroll reveals, image zoom, active-section navigation and a no-alert newsletter confirmation
- products and collections made more visible than the previous version

## Notes

- Current visuals use live image assets from the existing CS12 website.
- Next step can be converting this into a WordPress theme or block-based build.
