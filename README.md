# CS12HK

Luxury minimal homepage redesign prototype for CS12 Skincare Hong Kong.

## Files

- `index.html` — refined homepage concept
- `styles.css` — visual system and responsive layout
- `script.js` — mobile menu + Chinese / English switcher

## Direction used

- luxury minimal visual style
- bold new homepage structure
- Traditional Chinese first
- English switch prepared in the prototype
- products and collections made more visible than the previous version

## Notes

- Current visuals use live image assets from the existing CS12 website.
- Next step can be converting this into a WordPress theme or block-based build.
